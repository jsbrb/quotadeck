# Privacy Policy — quotadeck

Last updated: 2026-10-04

quotadeck is a browser extension that shows your GLM Coding Plan (Z.AI /
Zhipu) usage and balances in the browser toolbar.

## What data quotadeck handles

- **Your API key.** The credential you paste into the extension is stored
  exclusively in the extension's local storage (`chrome.storage.local`) on
  your own device. It is never synced, never logged, and never sent anywhere
  except as the authentication header of requests to the official Z.AI /
  Zhipu endpoints (`api.z.ai`, `open.bigmodel.cn`).
- **Your usage data.** Usage and balance figures returned by those endpoints
  are rendered in the badge and popup and cached in local storage. They never
  leave your device.

## What quotadeck does NOT do

- It does not collect, share, or sell any personal data.
- It contains no analytics, no tracking, no advertising, and no remote code.
- It does not read the content of the pages you visit.

## Data retention and deletion

Usage data stays in local storage until you remove the extension. Removing
your stored key (popup → Settings → Revoke) deletes the credential
immediately. Uninstalling the extension deletes all stored data.

## Contact

For questions about this policy, open an issue at the repository hosting
this file or contact the publisher.
